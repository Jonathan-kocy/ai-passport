# Flappy Bird(feature/flappy-bird)

适用于 FoloToy AI Passport 的经典"再来一局"飞行游戏。操控一只原创的橙色小鸟穿过
无尽的管道缝隙,每穿过一个缝隙得一分。本应用用自己的界面取代了基线硬件测试菜单。

## 按键

| 按键 | 游戏中 | 菜单与卡片 |
| --- | --- | --- |
| `UP` 按下 | 扇翅(默认力度下上升约 36 px) | 标题页和设置:向上选择;准备:开始;暂停:继续 |
| `DOWN` 按下 | 降低音量:`HIGH`、`MED`、`LOW`、`MUTE`,然后回到 `HIGH` | 标题页和设置:向下选择;准备和暂停:降低音量;教程:无作用;结束页:返回标题 |
| `OK` 按下 | 暂停 | 标题页:确认;设置:更改所选数值;结束页:重来(0.7 s 防误触后) |
| 暂停时轻按 `OK` | 继续 | 教程第 3 步:继续 |
| 暂停时长按 `OK` | 退出到标题页 | 教程:跳过;准备:返回标题页 |

游戏响应按下沿(`BSP_BTN_PRESS`)而不是单击,所以扇翅没有单击判定延迟。长按只有
从一次新的按下开始才算数:触发暂停的那次按下不会同时触发退出。

## 界面

- **标题页**:标志、`PLAY` / `TUTORIAL` / `SETTINGS` 菜单,以及当前难度的最高分。
- **设置**:用 `UP` 和 `DOWN` 选择一行,用 `OK` 更改数值,`BACK` 行返回标题页。
  - `VOLUME`:`HIGH`、`MED`、`LOW` 或 `MUTE`。
  - `FLAP`:每按一次小鸟上升的高度:`SOFT` 约 26 px、`NORMAL` 约 36 px、`STRONG` 约 49 px。
  - `DIFFICULTY`:`EASY`、`NORMAL` 或 `HARD`,每种难度有各自的最高分。
  - `THEME`:`DAY`、`SUNSET`(有太阳)或 `NIGHT`(有月亮和星星)。
- **教程**:首次游戏前自动运行(也可从标题菜单进入)。五个交互步骤:用 `UP` 扇翅、
  用 `OK` 暂停、用 `OK` 继续、飞过一道宽的练习门,最后了解在哪里找到 `SETTINGS`。教程中不会
  失败;在练习门撞到只会重新开始这一步。除欢迎卡外,任何一步长按 `OK` 都可跳过教程。
- **准备**:小鸟悬停,按 `UP` 开始。
- **游戏中**:顶部显示分数,左上角显示音量档位,右上角显示电量。
- **暂停**:场景变暗并显示继续/退出提示。
- **结束**:本局分数、最高分,创纪录时显示 `NEW BEST!` 徽章。

每局在前 20-30 分内缓慢变难。相邻缝隙中心的高度差不超过 70 px。

| 难度 | 管道速度 | 缝隙高度 |
| --- | --- | --- |
| `EASY` | 约 105 到 140 px/s | 116 到 96 px |
| `NORMAL` | 125 到约 170 px/s | 100 到 80 px |
| `HARD` | 约 145 到 203 px/s | 92 到 76 px |

## 声音、存储与电量

- 短促的合成音效(扇翅、音量预览、得分、撞击、坠落、新纪录、菜单、教程步骤、暂停)
  由专用工作任务以 16 kHz 通过 ES8311 播放。音频初始化失败时游戏静音运行。
- 四个音量档位决定 codec 输出:`HIGH` 65 %、`MED` 50 %、`LOW` 35 %,以及不播放任何
  声音的 `MUTE`。默认为 `HIGH`。每次调节都会以新音量播放一段简短预览(`MUTE` 除外)。
- 最高分、教程完成标志和设置保存在 NVS 命名空间 `flappy`(`best_e`、`best`、`best_h`、
  `tut_done`、`volume`、`flap`、`diff`、`theme`)。加入难度之前保存的分数算作 `NORMAL`。
  写入在工作任务中进行,且只在数值变化时写。
- 每 15 s 读取一次电量。CW2017 电量计不可用时只显示空电池图标,绝不显示数字。

在 `0x0` 烧录合并镜像可能会重置 NVS,从而清除已保存的最高分和设置并重新显示教程。见
[烧录与已存数据](development/engineering/firmware-layout.zh_CN.md#烧录与已存数据)。

## 实现结构

| 文件 | 作用 |
| --- | --- |
| `main/flappy_model.[ch]` | 可移植规则:Q8 定点的 10 ms 固定步长物理、管道、计分、教程、全部按键规则 |
| `main/flappy_sprite.[ch]` | 程序化生成的小鸟精灵(三帧翅膀),无二进制素材 |
| `main/flappy_sfx.[ch]` | 程序化音效,按 16 ms 分块渲染 |
| `main/flappy_text.h` | 所有用户可见字符串(仅可打印 ASCII) |
| `main/flappy_ui.[ch]` | 一次性建立的 LVGL 界面,每帧只调整对象位置 |
| `main/flappy_services.[ch]` | 音频、NVS 与电量工作任务 |
| `main/main.c` | 启动、按键队列和 16 ms LVGL 定时器游戏循环 |

按键回调只把事件放入队列。游戏循环是 LVGL 定时器,因此模型和所有 LVGL 对象只在
LVGL 任务中访问。声音、存储和电量读取从不在按键或 LVGL 上下文中运行。

界面使用内置 Montserrat 14/20/32/48 字体,覆盖可打印 ASCII 和 LVGL 电池符号;
`tests/test_flappy_fonts.py` 会在出现非 ASCII 字符串或未启用的字号时失败。
界面不显示中文。

## 验证

```bash
./tools/validate.sh --static   # 包含 test_flappy_model、test_flappy_assets、test_flappy_fonts
./tools/validate.sh            # 完整门禁;需要已激活的 ESP-IDF 5.5.3
```

模型测试覆盖完整教程、跳过规则、菜单、暂停/退出的按下与长按规则、游戏结束、
最高分、音量控制、设置界面、所有难度与扇翅力度的组合、帧时长钳制,以及在 20 个随机种子上各运行 60 秒的自动驾驶,
以证明生成的关卡始终可以通过。

## 设备验收

| 场景 | 准备与操作 | 预期结果 |
| --- | --- | --- |
| 首次启动 | 在 `0x0` 烧录后上电 | 显示教程欢迎卡;右上角显示电量 |
| 教程 | 按五个步骤操作 | 每步只在对应按键时前进;`DOWN` 不改变音量徽章;练习门撞到后重试;设置卡片等待 `OK`;之后进入准备 |
| 跳过 | 在第 1 步长按 `OK` | 进入准备;重启后显示标题页而不是教程 |
| 游戏 | 按 `UP` 开始,飞过若干管道 | 运动流畅,每按一次扇一次翅,每个管道只加一分,有音效 |
| 音量 | 游戏中按四次 `DOWN`,每次都听一下 | 徽章依次显示 `MED`、`LOW`、`MUTE`、`HIGH`;声音逐渐变小直至无声;小鸟的飞行不受影响 |
| 音量记忆 | 选择 `LOW`,然后断电再上电 | 徽章仍显示 `LOW`;声音保持较小 |
| 设置菜单 | 在标题页选择 `SETTINGS`;按 `UP` 和 `DOWN`;在每一行按 `OK`;选择 `BACK` | `UP` 和 `DOWN` 只移动高亮;`OK` 更改数值;`BACK` 返回标题页 |
| 扇翅 | 先用 `SOFT` 玩,再用 `STRONG` 玩 | 每按一次小鸟明显上升得更少,然后更多 |
| 难度 | 先玩 `EASY`,再玩 `HARD` | 管道先慢且缝隙宽,然后快且缝隙窄;各自保留最高分 |
| 主题 | 依次选择每个主题 | 天空和景物改变;文字保持清晰 |
| 设置记忆 | 更改所有行,然后断电再上电 | 所有数值都保留 |
| 暂停 | 按 `OK`,等待,轻按 `OK`;再次暂停后长按 `OK` | 场景冻结并恢复;长按退出到标题页 |
| 结束 | 撞到 | 坠地并显示结束卡;0.7 s 内的按键被忽略 |
| 最高分 | 打破纪录后重启 | 显示 `NEW BEST!`;断电后最高分仍保留 |
| 电量 | 分别在电池供电和电量计缺失时观察 | 显示百分比和图标,低于 15 % 变红;不可用时只显示轮廓 |

还需查看固件约每 15 s 输出一次的 `stats:` 日志:LVGL 内存峰值(相对 48 KB 内存池)、
空闲堆和最长帧时长。
